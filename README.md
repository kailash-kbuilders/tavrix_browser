# Tavrix Browser

A fast, Chrome-style mobile browser built with Flutter. Android and iOS.

This is the empty project scaffold — screens and features are added from the PRD.

## Run locally

You need the Flutter SDK installed.

```
flutter pub get
flutter run
```

The `android/` folder is generated by the GitHub Actions workflow on the first
build. For iOS, macOS, Windows and Linux platform folders, run this once on your
machine:

```
flutter create . --platforms=ios,windows,macos,linux
```

iOS builds need macOS with Xcode.

## Build the APK

Push to `main` and the **Build APK** workflow compiles a release APK and attaches
it as an artifact. Run the workflow manually (Actions → Build APK → Run workflow)
to also get the APK on a GitHub Release named `apk-latest`.

There is no Flutter SDK in the build sandbox this project was generated in, so the
APK always comes from the GitHub Actions workflow.
